# Movie-Recommender-system
Movie Recommender System 🎬  
A simple movie recommender system made using Python and Streamlit.  

What it does: 
-Select a movie 
-Get 5 similar movie recommendations 
-View movie posters 

Built With:
-Python 
-Streamlit 
-Pandas 
-Scikit-Learn
